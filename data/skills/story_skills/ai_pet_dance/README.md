# AI 宠物跳舞短视频 · 叙事技能包

## 简介

本技能包为 **AI 宠物跳舞短视频** 类型提供一套完整的叙事与制作参考，覆盖从单镜头表演节奏规划到生产执行的全流程。适用于纯兽态3D渲染风格的宠物萌态律动短视频。

## 核心理念

- **兽态即萌点** — 角色严格保留全身真实兽态（大头短身、短小四肢、真实前爪），舞蹈是"真实宠物在音乐下的萌态反应"，不是拟人化舞蹈
- **单镜头即力量** — 一个连续镜头不剪切不拼接不按秒分段，观众注意力集中在角色本身，AI生成工具的角色一致性最好
- **一段连续流转** — 整条视频是一段连续的表演流转（开场-递进-高潮-收束），**严禁**拆成"片段一/片段二/片段三..."分镜表，**严禁**按"0-3s/3-6s/6-10s"等时间分段
- **BGM + 动作卡拍** — 不是镜头切换卡节拍，而是角色动作卡音乐节拍（摆头/拍爪/转身/定格pose）
- **换装即内容** — 宠物服饰跨视频更换，每套服饰独立可识别，换装系列是核心内容形式

## 技能文件说明

### 1. 表演节奏规划 (`director_planning_dance.md`)

导演在 **表演节奏规划阶段** 使用的技法参考，定义宠物跳舞短视频在选曲、单镜头表演设计、动作节拍类型与表演节奏模板上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 选曲与节奏匹配 | BPM选择、节奏类型与宠物动作适配 |
| 单镜头表演结构 | 建立期→发展期→高潮期→收束期（**创作思路·非时间分段**） |
| 动作节拍类型 | 七种萌态动作与音乐适配 |
| 内容子类型 | 萌态律动/换装展示/情境萌态/品牌植入/系列化 |

### 2. 单镜头表演技法 (`director_storyboard_table_dance.md`)

导演在 **单镜头表演阶段** 使用的技法参考，定义宠物跳舞短视频在景别、运镜微调、画面构图与质量检查上的表演技法。**单镜头一镜到底，严禁拆分镜/按时间分镜/做片段表**。

| 章节 | 内容概要 |
|---|---|
| 单镜头表演流转思路 | 建立→递进→高潮→收束（连续流转） |
| 运镜微调 | 固定/缓推/缓拉/轻微摇移（变化≤1次） |
| 画面构图 | 中心构图/三分法/低角度仰拍/俯拍 |
| 严禁的输出格式 | ❌ 时间分段 / ❌ 片段表 / ❌ 5段×3s |
| 正确输出格式 | 单段连续表演描述 + 单段连续视频生成提示词 |
| 质量检查清单 | 单镜头连贯性/表演节奏/视觉质量/时长合规 |
