# AI 宠物跳舞短视频 · 叙事技能包

## 简介

本技能包为 **AI 宠物跳舞短视频** 类型提供一套完整的叙事与制作参考，覆盖从单镜头表演节奏规划到生产执行的全流程。适用于纯兽态3D渲染风格的宠物萌态律动短视频。

## 核心理念

- **兽态即萌点** — 角色严格保留全身真实兽态（大头短身、短小四肢、真实前爪），舞蹈是"真实宠物在音乐下的萌态反应"，不是拟人化舞蹈
- **单镜头即力量** — 一个连续镜头不剪切不拼接，观众注意力集中在角色本身，AI生成工具的角色一致性最好
- **BGM + 动作卡拍** — 不是镜头切换卡节拍，而是角色动作卡音乐节拍（摆头/拍爪/转身/定格pose）
- **换装即内容** — 宠物服饰跨视频更换，每套服饰独立可识别，换装系列是核心内容形式
