# 宠物拟人化Vlog约束 · Pet Anthropomorphic Vlog · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以奶油白（C1）、焦糖棕（C2）、暖阳橙（C3）为基底色，整体色温偏暖（4800-5800K），饱和度中等（50-70%），呈现毛绒治愈系的温暖柔和感
- **冷暖叙事对比** — 暖色（暖阳橙 C3、蜜桃粉 C6）作为情感升温与温馨时刻的视觉信号。冷色（雾霾蓝 C5、薄荷奶 C10）用于清晨、夜晚、户外清新段落。冷暖切换应与生活节奏与情绪弧线同步
- **冷暖分配策略** — 日常居家段落保持暖色调基底；冷色用于清晨/夜晚/室外段落，用冷暖对比做时间流转与情绪转折
- **色盘先行原则** — 段落规划需先绑定情绪场景（居家/萌趣/出游/夜晚/温情等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、赛博霓虹色、冷硬工业色彩体系均与本风格不兼容

### 情绪向场景色（发疯/反差向补充）

> 治愈向用现有暖色体系；发疯吐槽/反转/社恐等短视频情绪需要冷暖对比制造张力（色名见 prefix.md 全局色彩盘）。

| 情绪场景 | 主色 | 辅色 | 氛围 |
|---|---|---|---|
| 发疯吐槽 | C9 炭灰 | C3 暖阳橙 + C5 雾霾蓝 | 中高对比，冷中带暖 |
| 反转发泄 | C3 暖阳橙 | C9 炭灰 + C6 蜜桃粉 | 突变对比，情绪爆发 |
| 社恐尴尬 | C7 灰玫瑰 | C5 雾霾蓝 + C8 浅燕麦 | 低饱和，缩感 |

### 色彩节奏（按情绪走向）

- **治愈向** — 暖色从头到尾，渐变式过渡
- **发疯向** — 冷→暖→冷的三段式情绪波动
- **反差向** — 前半段暖色铺垫 → 突然转冷 → 回暖收尾
- 色彩节奏切换仍遵守 prefix.md E1-E5 与色温/容差约束，禁高饱和荧光色

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **自然写实光为核心** — 照片级写实质感依赖真实光照（柔和环境光 + 真实方向光 + 自然阴影 + 景深）塑造真实毛发层次与体积，避免过曝与不自然的硬光

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 暖阳居家光 | 暖橙 + 奶油白 + 焦糖棕 | 居家日常 |
| B | 蜜桃柔光 | 蜜桃粉 + 暖橙对比 | 萌趣瞬间、升温段 |
| C | 清晨冷柔光 | 雾霾蓝 + 奶油白 + 薄荷奶 | 清晨、清新段 |
| D | 黄金时刻光 | 暖橙 + 浅燕麦 + 焦糖棕 | 出游、咖啡馆、温馨段 |
| E | 夜晚暖灯光 | 雾霾蓝 + 暖橙点缀 + 炭灰 | 夜晚居家、静谧段 |
| F | 怀旧柔调光 | 浅燕麦 + 蜜桃粉 + 灰玫瑰 | 回忆/温情 |

- **冷暖光分配** — 暖光（暖阳居家光/黄金时刻光）适用于温馨升温段落；清晨/夜晚段落用冷柔光。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

### 光线真实感层级

> 6 套光影方案偏「电影感」，适合情绪高潮镜头。但短视频的「真实 vlog 感」反而来自不那么完美的光——过于精致的灯光会削弱真实感。

| 层级 | 描述 | 适用 |
|---|---|---|
| L1 手机级 | 自然窗光/灯光，明暗不均，轻微噪点感 | 日常 vlog 镜头（多数） |
| L2 电影级 | 柔和方向光，真实阴影，景深层次 | 情绪高潮镜头 |
| L3 效果图 | 过曝、均匀柔光、无阴影区域 | 禁用 |

### 光线瑕疵美学（真实感来源）

- 允许窗边轻微过曝
- 允许夜晚室内暗部噪点
- 允许光源入镜（台灯/屏幕光晕）
- 这些「瑕疵」恰是 vlog 真实感的来源，但仍须避免 L3 效果图式的均匀完美打光与样板间感（见 art_scene.md X7/X8）

## 三、质感方向

- **照片级真实毛发** — 本风格核心：真实毛发清晰自然、皮毛层次、自然透光感、真实解剖结构、照片级写实（photorealistic，而非精致商业摄影/CG/3D渲染）
- **真实光泽 + 自然质感** — 这是画面质感的锚点。追求自然真实的毛发与神态，而非卡通/插画/黏土/玩具感
- **保留真实动物全身特征（情境化拟人）** — 所有角色完整保留种属真实身体特征（耳形/口鼻/胡须/四肢/全身真实毛发与真实动物体态）；**做手部操作（吃饭/做饭/用电脑等）时后腿坐起/立起、前爪操作，走路/移动时回归自然四足兽态、不直立行走**；穿戴宠物专用服饰。即使立起也须保留真实兽态（相对大头、短身圆润、短小四肢、真实前爪），身体不可人形化，**避免修长躯干、宽肩、人手、人腿剪影等过度拟人**
- **生活Vlog质感** — 画面像真实生活记录：自然景深、handheld感、生活细节、烟火气，营造陪伴式真实感
- **可爱来自神态（呆萌优先）** — 通过真实拟人反差（真实宠物过人类生活）与生活仪式感传递情感，靠真实神态而非卡通变形；**优先展现呆萌感**：圆润大眼、无辜眼神、微微歪头、放空发呆、笨拙可爱的小动作、种属本能破功的呆愣瞬间，是本风格最大的萌点来源

## 四、生活场景空间元素

宠物拟人Vlog特有的场景元素及其视觉叙事功能：

- **居家生活空间** — 沙发/餐桌/床铺/厨房等，是天然的生活叙事载体，用生活物件与布局制造温馨陪伴感
- **打工/职场空间** — 办公室（工位/电脑/工牌/文件堆）、地铁车厢（扶手/座椅/早高峰人群）、茶水间、写字楼街角等打工人场景，是发疯吐槽/社恐共鸣等短视频情绪的天然舞台；用职场道具（键盘/工牌/会议白板）传递打工人共鸣
- **公共场所默认定位杭州** — 所有公共/室外场景（街道、地铁、集市、公园、湖畔、商圈、通勤等）无明确设定时默认落在杭州，呈现江南城市风貌（梧桐街道、白墙黛瓦与现代街区、温润空气感，可含西湖/钱塘江/运河/武林商圈氛围意象），画内招牌/路牌用简体中文；私人室内空间不受约束。详见 art_scene.md R5b
- **生活道具/宠物友好元素** — 马克杯、相机、绿植、猫爬架、玩具球等生活物件兼具表意功能，传递角色生活方式与性格
- **窗光/暖灯/光晕** — 本风格重要的情感手段。窗边自然光 = 治愈清新、暖黄灯光 = 温馨陪伴、黄金时刻 = 浪漫升温
- **段落间用光线过渡** — 利用时段光线变化（清晨→正午→黄昏→夜晚）做段落衔接与情绪缓冲，呈现Vlog式的一天流转
- **转折点用氛围变化** — 优先使用画面手段（光线变化、色温转变、景别推进、生活细节特写）而非依赖对白解释

## 五、声音约束（零配乐、零人声）

> **本风格的声音只有三种：动物真实叫声 + 环境音 + 动作音。不要有任何配乐、旁白、人声。** 沉浸感完全靠生活环境音与动物本能声音营造。

### 声音组成（仅此三类，无例外）

| 类型 | 内容 | 示例 |
|---|---|---|
| 动物真实叫声 | 种属真实叫声表达情绪 | 猫呼噜/喵呜、狗轻吠/哼唧、兔咕咕 |
| 环境音 | 生活空间的自然音 | 咖啡机咕嘟、烤箱叮、翻书沙沙、窗外鸟鸣、雨声、猫爪踏地声、键盘声 |
| 动作音 | 角色与物件交互发出的声音 | 餐具碰撞、水流声、杯沿轻碰、爪子敲桌面 |

### 严禁（绝对不可出现）

- ❌ 背景配乐/音乐（任何乐器、任何轻重程度）
- ❌ 旁白/口播/画外音（任何人声独白）
- ❌ 角色用人类语言对话/对口型台词/夸张拟人配音
- ❌ 任何人声（哼唱、唱歌、笑声等人类发声）

### 环境音设计要求

- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计
- 环境音层次越丰富，Vlog沉浸感越强——用声音细节替代配乐营造氛围
- 动物叫声要自然、随情绪变化（开心时呼噜、好奇时轻哼、惊讶时短促叫声）

### 短脚本平台配乐例外（仅后期叠加层）

> 上述「零配乐」规则约束**视频生成阶段**（AI 生成的画面/视频片段始终不含配乐与人声，保持纯净环境音设计）。**短脚本（15-25s）面向小红书/抖音投放时**，可在**后期剪辑层**叠加一段轻快 BGM 与字幕以贴合平台节奏。

### 声音分档（按内容类型选用）

| 档位 | 配乐 | 人声 | 适用 |
|---|---|---|---|
| 纯环境音（保留） | 无 | 无 | ASMR 治愈向、睡前向 |
| 轻 BGM | 轻快卡点背景乐 | 无 | 日常 vlog |
| BGM + 字幕 | 轻快 BGM | 字幕代替口播 | 吐槽/发疯向 |
| 禁用 | 任何 | 任何人类语音旁白 | 所有档位 |

| 编号 | 规则 |
|---|---|
| B1 | BGM 与字幕仅作为后期剪辑叠加层，**不进入视频生成提示词**；生成阶段仍严格零配乐零人声零叠字 |
| B2 | 治愈向默认纯环境音；日常向可加轻 BGM；吐槽/发疯向用 BGM + 字幕 |
| B3 | BGM 选轻快、不抢戏，音量低于环境音/动物声，不得盖过核心音效 |
| B4 | 仍严禁任何人声旁白、角色人类语言对白、夸张拟人配音（字幕代替口播，不用真人语音） |

### 字幕设计规范（后期叠加层）

- 短脚本用大字幕（占画面约 1/4-1/3），快速出现/消失
- 吐槽/发疯向字幕可用略夸张的字体动效
- 字幕内容 = 角色内心独白（第一人称口语化）
- 每句 5-10 字，不超过 2 行
- 字幕为后期 UI 层，**不写入画面生成提示词**（画面仍为纯视觉，见 director_storyboard 美学禁止项）
