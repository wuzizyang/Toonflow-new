---

## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 宠物拟人化Vlog（Pet Anthropomorphic Vlog） |
| **二级风格** | 照片级写实·真实摄影（实拍质感） · 真实毛发 · 真实动物体态 · 情境化拟人（操作态立起·行动态四足） |
| **情感基调** | 温暖治愈 · 真实生活 · 呆萌可爱 |
| **质感锚词** | 逐根真实毛发、皮毛细节、自然次表面散射光泽、日常生活随拍质感、自然朴素色彩 |

> **核心定位**：角色是「真实存在的宠物」过着人类生活——完整保留真实动物的全身毛发质感、真实动物体态、解剖结构与神态，**照片级写实·真实照片实拍质感**（像真实相机拍下，而非CG/3D渲染），而非卡通/黏土/插画。**拟人是情境化的**：只有"需要用手的操作行为"（吃饭/做饭/用电脑/冲咖啡/看书）才拟人——后腿坐起/立起、前爪像手一样操作；**走路、移动等位移行动一律保持自然四足兽态、不直立行走**。穿戴**宠物专用服饰**（宠物卫衣/背心/围嘴/披风/项圈，非人类成衣）。身体始终是真实兽态（相对大头、短身圆润、短小覆毛四肢、真实前爪、含背微弓），下半身保留覆毛兽腿与爪足、不穿人类长裤，**避免人类化的修长躯干、宽肩、五指人手、挺直军姿与人腿剪影**。

## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：毛色、眼睛、动物种属特征的审美方向 |
| L2 软约束 | 中 | 场景色、服饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 节日/出游/特殊场景可临时突破局部色彩，但需保留整体毛绒治愈逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 毛色基准 | C1 奶油白 / C2 焦糖棕 / C9 炭灰 | 按角色种属设定，默认优先，允许明度微调 |
| 眼睛/瞳色基准 | C9 炭灰 + 高光 | 默认优先，圆润有神，允许琥珀/蓝/绿偏移 |

### 软约束色（推荐优先）

> C3/C4/C5/C6/C7/C8/C10 为推荐色域，用于服装、装饰、背景、暖光、自然环境等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整色温，再调整饱和度 |
| E4 | 治愈向默认遵循「暖底 + 冷暖对比」：暖色铺底，冷色用于背景/次要元素 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 暖调 4800-5800K（推荐） | 治愈温暖主基调 |
| 毛色色温 | 微暖 5000-5500K（推荐） | 绒毛有温度有生命感 |
| 对比度 | 中等（建议保持） | 柔和过渡，不过分强烈 |
| 饱和度 | 中等 50-70%（建议区间） | 治愈系柔和色调，不刺眼 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±10° |
| 饱和度偏移 | ±12% |
| 明度偏移 | ±12% |

> 例外场景：节日、出游、情绪高潮镜头可使用更暖或更鲜明局部色块；但禁止高饱和荧光色与赛博霓虹色入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「宠物拟人化 + 照片级写实真实摄影」风格锚定词（photorealistic photograph, real-life photo, shot on DSLR, true-to-life），**以真实照片实拍质感为准，避免CG/3D渲染塑料感** |
| R2 | 必须声明「保留真实动物全身特征与体态」+ **情境化姿态**：操作行为（吃饭/做饭/用电脑等）用后腿坐起/立起 + 前爪操作；走路/移动用自然四足兽态。身体不可人形化、不可人类笔直站立行走 |
| R3 | 毛发必须使用「逐根真实毛发 + 皮毛细节 + 次表面散射」（detailed individual fur strands, realistic fur grooming, subsurface scattering）；着装为**宠物专用服饰**（非人类成衣） |
| R4 | 造型必须使用「真实解剖结构 + 真实比例」，可爱来自神态而非卡通变形 |
| R5 | 氛围必须声明「真实生活Vlog感 + 自然写实光照（柔和环境光/真实阴影/景深）」 |
| R6 | 角色须**优先展现呆萌可爱**：圆润大眼、无辜眼神、微微歪头、放空发呆、笨拙可爱的小动作与种属本能破功的萌点；萌来自真实神态，**不靠卡通变形** |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/插画/黏土/2.5D扁平/玩具感」等非写实质感（cartoon, illustration, claymation, toy-like, flat, cel-shaded） |
| X2 | 严禁「失去真实动物身体特征（头部/体态/毛发）的纯人类或人形化躯干角色」 |
| X3 | 严禁「高饱和荧光色/赛博霓虹色」 |
| X4 | 严禁「恐怖/怪诞/扭曲拟人/人兽不分的畸形造型」 |
| X5 | 严禁「黑暗暴力/惊悚/成人向内容」 |
| X6 | 严禁「直立行走/人类化迈步走路」——走路、移动、奔跑等位移行动须为**自然四足兽态**；后腿立起仅用于"用手的操作行为"（操作态）。设定图为操作态，行动镜头为四足兽态 |
| X6b | 严禁「过度拟人」：人类化修长躯干/宽肩锁骨/修长手臂/灵巧五指人手/挺直军姿/垂直脊柱；身体须保留真实兽态（大头短身、含背微弓、短小覆毛四肢、真实前爪与肉垫、趾行爪足） |
| X6c | 严禁「人腿剪影」与「人类成衣」：长裤/长袜遮盖后腿造成人类双腿轮廓；人类成衣剪裁。着装为宠物专用服饰、以上身/披挂为主，下半身保留动物覆毛后腿与爪足 |
| X7 | 严禁「塑料感/橡胶感/无细节的纯色绒毛」，毛发必须真实有层次与光泽 |
