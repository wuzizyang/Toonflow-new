# 场景图生成 · 宠物拟人化Vlog约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载Vlog生活叙事与情绪功能，是有温度的生活空间，不是纯背景板
2. **生活质感** — 居家/咖啡馆/街头/户外等真实生活场景，充满烟火气与日常细节
3. **毛绒友好尺度** — 场景物件尺度与拟人宠物角色协调，圆润可爱，温馨亲切
4. **写实为锚（照片级真实·照片实拍优先·拒绝效果图）** — 场景一切画面必须达到**照片级真实**（像真实相机拍下来的照片，而非插画/绘画/渲染/CG），以**真实手机/相机随手拍下的生活照**为最高标准：有自然光的不均匀、有生活杂物的真实空间。**绝不能像"室内设计渲染效果图/样板间/3D效果图"——那种光照过于均匀完美、地面反光过于干净的"CG感"是本风格大忌**。要的是"有人（有宠物）真的住在这里"的温暖真实生活感，不是"准备拍广告的完美空间"。

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 客厅/起居室 | 布艺沙发、地毯、绿植、电视、抱枕 | 温馨慵懒、居家放松 |
| 厨房/餐厅 | 餐桌、橱柜、餐具、食材 | 烟火日常、温暖治愈 |
| 卧室 | 床铺、床头灯、窗帘、绒毛玩偶 | 私密温馨、柔软安心 |
| 咖啡馆 | 吧台、咖啡机、木桌椅、暖光吊灯 | 惬意悠闲、生活仪式 |
| 工作室/书房 | 书桌、书架、绿植、电脑、文具 | 文艺专注、温暖宁静 |
| 浴室/盥洗 | 浴缸、镜子、毛巾、绿植 | 清爽舒适、日常照护 |

### 打工场景优先级（短视频补充）

> 打工人题材的核心场景，出镜率高，是发疯吐槽/社恐共鸣等情绪的天然舞台。

| 优先级 | 场景 | 原因 |
|---|---|---|
| P0 | 办公室/工位 | 打工人核心场景，出镜率最高 |
| P0 | 卧室（起床） | 周一综合征、赖床 |
| P1 | 地铁/通勤 | 早高峰挤车、社恐 |
| P1 | 茶水间 | 摸鱼偷闲 |
| P2 | 会议室 | 被老板点名 |
| P2 | 下班街角 | 治愈收尾 |

**场景设计原则**：
- 场景是「功能性背景」，不是「美学展示」
- 每个场景只保留 3-5 个核心道具，其余虚化
- 办公室场景核心道具：电脑 + 键盘 + 咖啡杯 + 绿植
- 须有「使用痕迹」（lived-in），但不堆砌杂物

## 四、室外场景

> **公共场所默认定位：杭州（江南城市风貌）**。所有公共/室外场景（街道、地铁、集市、公园、湖畔、商圈、写字楼街角、通勤场景等）在无明确设定时，一律默认落在**杭州**——呈现江南城市气质：梧桐行道树、白墙黛瓦与现代街区混搭、湿润温润的空气感、可点缀西湖/钱塘江/运河/武林商圈等地标氛围（氛围意象即可，不强制出现具体地标，不堆砌）。招牌/路牌/标识等画内文字默认用**简体中文**。私人室内空间（自家卧室/厨房/客厅）不受此定位约束。

> ⚠️ 过审提醒：地标只取「氛围意象」（如江南水乡街景、临湖步道、梧桐街道），**不照搬真实商标/品牌名/具体景区门票牌等**；画内中文招牌按 `director_storyboard.md` 画内文字规则保证清晰可读即可。

### 空间规范

| 维度 | 约束 | 提示词 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载Vlog空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与生活氛围 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 角色 | **严禁出现任何角色、人形、动物拟人形象** |
| 一致性 | 风格/材质/色调统一 |
| 光线 | 自然写实光照、真实光影、真实材质质感 |
| 画面比例 | 默认 1:1（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」与生活质感 |
| R2 | 必须体现「温馨生活Vlog氛围」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何角色** |
| R5b | **公共/室外场景无明确设定时默认定位杭州**（江南城市风貌：梧桐街道、白墙黛瓦与现代街区混搭、温润空气感，可含西湖/钱塘江/运河/武林商圈等氛围意象），画内招牌/路牌用简体中文；私人室内空间不受此约束 |
| R6 | 必须达到照片级真实质感：**只用单个 `photorealistic`，禁止堆叠 real-life photo / RAW photo / casual snapshot / shot on iPhone 等同义词（见 `prefix.md#S8`，否则触发审核）** + 「有人真的住在这里的生活感」（lived-in），**拒绝样板间/效果图感** |
| R7 | 必须指定「自然写实光照」（有方向感、有光斑、有阴影区的真实光，非均匀柔光箱打光）与真实空气感 |
| R8 | 必须达到照片级真实质感，材质纹理逼真自然可信，整体画面像真实照片而非插画/渲染/CG |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无层次/无生活质感 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何角色、人形、动物拟人剪影或轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 室内设计效果图/3D渲染效果图/样板间感/CG渲染海报/概念图/绘画感等**效果图/CG感**非真实照片质感（场景专属过审禁忌；全局「卡通/插画/2.5D扁平/玩具感」反写实质感见 `prefix.md#X1`、「塑料感/橡胶感/无细节纯色绒毛」见 `prefix.md#X7`） |
| X8 | 过曝梦幻光晕/过度精修/**光照过于均匀完美无阴影区/地面反光过于干净的"效果图感"**（场景专属；全局「高饱和荧光色/赛博霓虹色」见 `prefix.md#X3`） |
| X9 | 恐怖/阴森/破败压抑的非治愈氛围（除非剧情需要） |
