## 一、道具设计原则

1. **功能可读** — 道具用途一目了然，造型服务于功能与生活叙事
2. **圆润可爱** — 造型圆润、边角柔和，符合毛绒治愈萌系美学
3. **生活一致** — 所有道具须符合现代生活Vlog世界观，可含适度宠物友好元素
4. **尺度明确** — 道具尺度与拟人宠物角色协调，通过参照或标注暗示真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何角色、爪手、肢体，道具不可处于被持有/佩戴状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 材质/装饰细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 纯净中性灰 #E8E8E8 |
| 光线 | 自然写实光，真实材质质感清晰 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 柔和接触阴影，不强烈 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「纯净中性灰背景」 |
| R2 | 必须明确道具材质与工艺（真实质感表述） |
| R3 | 道具造型必须符合现代生活Vlog世界观，真实可信 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与角色同画面（本环节为纯道具图） |
| X3 | 出现任何角色形象，包括全身、半身、局部（爪手、手指、肢体等） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示角色存在的元素（如握持痕迹、佩戴视角、使用姿态） |
| X6 | 见 `prefix.md#X1`（卡通/插画/黏土/玩具感等非写实质感为全局严禁，运行时由 prefix 注入） |
| X7 | 材质过于复杂、风格突变 |
| X8 | 见 `prefix.md#X3`（高饱和荧光色/赛博霓虹色）与 `prefix.md#X4`（恐怖/怪诞元素），均为全局严禁，运行时由 prefix 注入 |
