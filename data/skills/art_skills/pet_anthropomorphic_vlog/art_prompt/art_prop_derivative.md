# 道具衍生状态生成 · 宠物拟人化Vlog约束手册

---

## 一、衍生原则

1. **轮廓锚定** — 道具核心造型/轮廓在所有状态中可识别
2. **状态可读** — 状态差异必须一目了然，观众能立即区分
3. **叙事服务** — 每种状态变体服务于特定Vlog剧情节点
4. **渐进退化** — 损伤/老化状态应有合理的物理逻辑
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何角色、爪手、肢体，道具不可处于被持有/佩戴状态，必须以静物陈列方式独立呈现

## 二、状态类型

### 2.1 使用状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 崭新 | 完好无损、色泽如新 | 所有道具 | 崭新、完好无损、色泽如新 |
| 日常使用 | 微磨损、自然使用痕迹 | 日用/配饰/玩具 | 使用痕迹、自然磨损 |
| 陈旧 | 明显年代感、色泽温润 | 信物/书本/纪念物 | 温馨陈旧、年代感、温润色泽 |

### 2.2 损伤状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 微损 | 小裂纹/小缺口/轻微磨损 | 陶瓷/玻璃/配饰 | 微损、轻微裂纹 |
| 破损 | 明显裂缝/断裂/破损 | 陶瓷/玩具/配饰 | 破损、明显断裂 |
| 残缺 | 仅剩部分/缺失 | 信物/玩具/纪念物 | 残缺、部分缺失 |

### 2.3 特殊状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 浸水/湿润 | 颜色加深、湿润感 | 书本/布料/纸品 | 浸水、湿润色泽 |
| 装满/盛装 | 杯中有饮品、盒中有物 | 杯具/餐具/礼盒 | 装满状态、盛装内容 |
| 包裹/封存 | 用布/盒子包裹 | 礼物/信物/纪念物 | 温馨包裹、礼物封装 |
| 点亮/发光 | 柔和发光、温暖光晕 | 灯具/装饰/电子物 | 柔和点亮、温暖光晕 |
| 装饰态 | 系丝带/贴贴纸装饰 | 礼物/日用/纪念物 | 装饰丝带、可爱贴纸 |

## 三、状态变体画面规范

### 单状态图

| 项目 | 约束 |
|---|---|
| 背景 | 纯净中性灰 #E8E8E8（与设定图一致） |
| 光线 | 自然写实光，真实材质质感 |
| 角度 | 与原设定图正面图一致 |
| 比例 | 道具占画面主体 70%+ |

### 状态对比图

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面并排展示 2-3 种状态 |
| 标注 | 每种状态下方标注状态名 |
| 一致性 | 角度/光线/背景完全一致，仅状态不同 |

## 四、材质状态变化规则

| 材质 | 崭新 → 日常 | 日常 → 陈旧 | 损伤表现 |
|---|---|---|---|
| 木质 | 色泽鲜亮 → 温润包浆 | 包浆 → 色泽加深 | 开裂/磨角/磕碰 |
| 陶瓷 | 釉面光洁 → 细微划痕 | 划痕 → 釉面温润暗哑 | 裂纹/缺口/碎裂 |
| 布料 | 平整鲜亮 → 自然褶皱 | 褶皱 → 柔软泛旧 | 撕裂/磨损/晕染 |
| 绒毛 | 蓬松鲜亮 → 自然压痕 | 压痕 → 微旧柔软 | 脱毛/磨平/污渍 |
| 金属 | 光亮 → 柔和包浆 | 包浆 → 温润旧色 | 划痕/凹陷/磨损 |
| 纸品 | 洁白平整 → 微微泛黄 | 泛黄 → 柔软卷边 | 撕裂/水渍/折损 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别 |
| R2 | 状态变化须符合物理逻辑 |
| R3 | 必须使用四宫格（2×2）布局：左上正面图+右上侧面图+左下背面图+右下细节特写 |
| R4 | 必须指定「纯净中性灰背景」，柔和均匀光 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别 |
| X2 | 违反物理逻辑的损伤 |
| X3 | 过度血腥/恐怖的损伤描绘 |
| X4 | 出现任何角色形象，包括全身、半身、局部（爪手、手指、肢体等） |
| X5 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X6 | 出现暗示角色存在的元素（如握持痕迹、佩戴视角、使用姿态） |
| X7 | 卡通/插画/黏土/玩具感等非写实质感 |
| X8 | 状态变化过于复杂、风格突变 |
| X9 | 高饱和荧光色/赛博霓虹色 |
