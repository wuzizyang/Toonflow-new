# 场景衍生资产生成 · 宠物拟人化Vlog约束手册

---

## 一、衍生原则

1. **空间一致** — 建筑结构/布局/材质/家具在所有变体中保持一致
2. **景别驱动** — 同一场景通过不同景别展示不同Vlog叙事功能
3. **时段切换** — 同一空间在不同时间段呈现不同光线色调
4. **天候变化** — 同一空间在不同天气下呈现不同色彩氛围
5. **写实为锚** — 所有变体必须保持照片级写实·真实摄影实拍质感，真实光照、真实材质，拒绝CG/3D渲染塑料感/卡通/插画/2.5D扁平

---

## 二、景别变体

### 景别定义

| 景别 | 范围 | 叙事功能 | 提示词 |
|---|---|---|---|
| 大全景 | 场景全貌 + 周围环境 | 建立空间感、定位 | extreme wide shot、大全景 |
| 全景 | 场景完整呈现 | 展示空间结构 | wide shot、全景 |
| 中景 | 场景局部区域 | 聚焦功能区 | medium shot、中景 |
| 近景 | 场景细部 | 氛围道具/生活细节特写 | close shot、近景 |
| 特写 | 极局部细节 | 材质/关键道具特写 | extreme closeup、特写 |

### 景别衍生规范

| 从基准图衍生 | 保持不变 | 允许变化 |
|---|---|---|
| 大全景 → 全景 | 建筑外观、整体布局 | 视角收窄、前景增加元素 |
| 全景 → 中景 | 材质、色调、光线 | 裁切聚焦、景深变化 |
| 中景 → 近景 | 材质、色调 | 聚焦细节、背景虚化 |
| 近景 → 特写 | 材质质感 | 微距聚焦、浅景深 |

## 三、时段变体

### 时段定义

| 时段 | 视觉特征 | 提示词 |
|---|---|---|
| 清晨 | 柔和冷调、浅色晨光 | 清晨柔光、浅色晨色 |
| 正午 | 明亮暖调、自然光充足 | 正午暖光、明亮自然光 |
| 黄昏 | 金色暖光、温馨光晕 | 黄昏金辉、暖色光晕 |
| 夜间（月光） | 冷蓝静谧、深色背景 | 月光冷蓝、静谧夜色 |
| 夜间（灯火） | 暖黄灯光、温馨光晕 | 暖黄灯火、温馨暗底 |

### 时段衍生规范

| 从基准时段衍生 | 保持不变 | 变化项 |
|---|---|---|
| 日间 → 黄昏 | 建筑/布局/材质/家具 | 光线暖化、金色光晕、长投影 |
| 日间 → 夜间 | 建筑/布局/材质/家具 | 整体变暗、增加灯火/月色 |
| 室内日间 → 室内夜间 | 空间结构、家具 | 暖黄灯光、温馨光晕 |

## 四、天候变体

### 天候定义

| 天候 | 视觉特征 | 提示词 |
|---|---|---|
| 晴天 | 明亮暖调、柔和阳光 | 柔和晴天、温暖阳光 |
| 多云 | 均匀柔光、柔和色调 | 柔和多云、均匀柔光 |
| 微雨 | 湿润反光、清新冷调 | 温柔细雨、湿润反光 |
| 飞雪 | 素白覆盖、暖冷对比 | 柔和飞雪、素白覆盖 |
| 暖阳 | 金色光晕、治愈温暖 | 治愈暖阳、金色光晕 |

### 天候衍生规范

| 从基准天候衍生 | 保持不变 | 变化项 |
|---|---|---|
| 晴 → 多云 | 建筑/布局 | 光线柔化、饱和度微降 |
| 晴 → 微雨 | 建筑/布局 | 增加湿润反光、地面水迹、色调偏冷 |
| 晴 → 飞雪 | 建筑/布局 | 增加积雪、雪花、色调偏白偏暖光 |
| 植被需随天候逻辑适配 | — | 雨后清新、雪覆植被 |

## 五、角度变体

### 角度定义

> 衍生图相对参考图，可在以下角度维度上进行切换。调用方会传入参考图 + 目标角度描述，本文件只定义角度语汇与一致性约束。

| 角度 | 描述 | 提示词 |
|---|---|---|
| 正面/前视 | 与参考图相比，视线朝向场景正面 | front view、eye level |
| 侧面（左/右） | 朝场景左/右侧 90° 平视 | left side view / right side view |
| 背面/后视 | 朝场景背面 180° | back view |
| 俯视 | 高位俯瞰，呈现整体布局 | high angle、bird's eye view |
| 仰视 | 低位仰望，强调高大主体 | low angle |
| 近景推进 | 同方向但镜头推进，聚焦局部 | push-in、closer angle |
| 自由角度 | 调用方自定义的任意角度描述 | 按 `{目标角度}` 注入 |

### 角度衍生规范

| 项目 | 约束 |
|---|---|
| 参考一致性 | 建筑结构/布局/材质/色调/季节/天候必须与参考图一致 |
| 视点 | 同一场景中心点，仅角度切换；视线高度可随角度调整 |
| 光照逻辑 | 保持柔和温暖光照逻辑，与参考图一致 |
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 角色 | **严禁出现任何角色、人形、动物拟人形象** |
| 画面比例 | 默认 1:1（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景空间结构与家具在所有变体中保持一致 |
| R2 | 时段变体必须调整光线色调与氛围 |
| R3 | 天候变体必须适配材质表面与色彩 |
| R4 | 衍生图必须为「单画面」，不得拼接多视图/网格/分屏 |
| R5 | 衍生图必须与参考图保持建筑结构/材质/色调一致，仅按指定角度切换视点 |
| R6 | 场景图中**严禁出现任何角色** |
| R7 | 根据用户提供的信息自行判断变化维度（角度/景别/时段/天候），未提及维度留空省略 |
| R8 | 必须指定「照片级写实·真实摄影实拍」关键词（real-life photo / shot on smartphone / casual snapshot） |
| R9 | 必须指定「自然写实光照」 |
| R10 | 材质须为真实质感，自然可信 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 变体间建筑结构/布局/家具不一致 |
| X2 | 天候与季节矛盾（夏天飞雪等） |
| X3 | 变体间材质/风格突变 |
| X4 | 出现任何角色、人形、动物拟人剪影或轮廓 |
| X5 | 画面被拼接成多视图/网格/分屏布局 |
| X6 | 卡通/插画/黏土/2.5D扁平/玩具感等非写实质感 |
| X7 | 高饱和荧光色/赛博霓虹色 |
| X8 | 恐怖/阴森/破败压抑的非治愈氛围（除非剧情需要） |
