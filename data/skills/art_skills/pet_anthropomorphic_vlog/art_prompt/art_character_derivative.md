# 人物衍生资产生成 · 宠物拟人化Vlog约束手册

---

## 一、叠加原则

1. **种属不变** — 叠加后动物头部特征（耳形/口鼻/胡须/毛色）必须与底模完全一致
2. **姿态不变** — 保持底模动物自然后腿立起姿态（含背微弓、前爪收胸前、趾行爪足），禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换种属）
4. **风格统一** — 所有服化元素服从同一毛绒治愈Vlog美学体系
5. **质感不降** — 叠加后绒毛与体积质感标准不低于底模
6. **纯服化范畴** — 仅叠加造型/发饰/服饰/配饰，禁止引入道具、场景、环境、动作

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 基础形象底模，不修改（含种属头部特征） |
| L1 | 面部状态（决策层） | 先分析用户线索，再决策「自然态 / 精神态 / 特殊态」表现强度 |
| L2 | 头部造型 | 耳朵装饰/头顶绒毛打理 + 头饰（帽子/发夹/头巾） |
| L3 | 内搭 | 替换基础内搭（打底衫/针织等） |
| L4 | 外衣/主服 | 卫衣/外套/裙装/西装等 |
| L5 | 配饰 | 围巾/眼镜/项圈铃铛/背包/胸针 |

## 三、面部状态约束（L1）

### 底模到衍生面部表现策略（关键）

> 角色底模为自然态，衍生资产默认根据用户线索调整面部精神状态与气色，而非僵硬保持原态。系统应分析线索并在自然态、精神态、特殊态之间决策强度。

### L1 线索分析与状态决策

| 步骤 | 处理内容 | 决策结果 |
|---|---|---|
| S1 | 提取用户线索：面部状态词、情绪词、强度词 | 形成状态需求摘要 |
| S2 | 过滤非面部线索：道具/场景/动作/姿态词不作为依据 | 防止误判 |
| S3 | 匹配状态矩阵并给出强度档 | 自然态 / 精神态 / 特殊态 |
| S4 | 生成最终 L1 提示词 | 只输出结论，不输出分析过程 |

### 线索到状态映射（执行口径）

| 线索类型 | 典型线索 | L1 决策 |
|---|---|---|
| 无明显面部强调线索 | 仅服饰/造型变化 | 自然态 |
| 轻微面部线索 | 精神、明亮、可爱、有活力 | 精神态（眼神更亮、气色更佳） |
| 明确委屈/疲惫线索 | 委屈、困倦、生病、耳朵下垂 | 特殊态（耳朵垂、眼神柔弱） |
| 明确节日/亮相线索 | 盛装、节日、出游亮相 | 精神态（受控，气色饱满有神） |

### 面部状态矩阵

| 状态 | 适用场景 | 核心提示词 |
|---|---|---|
| 自然萌态 | 日常、居家 | 自然神情、圆润大眼、柔和绒毛 |
| 活力精神态 | 出游、互动、欢乐 | 眼神明亮、耳朵竖立、气色饱满 |
| 慵懒放松态 | 睡前、休憩 | 半眯眼、耳朵微垂、放松神情 |
| 委屈柔弱态 | 受挫、生病 | 眼神湿润、耳朵下垂、神情委屈 |
| 节日亮相态 | 节日、盛装 | 眼神有神、气色明亮、精致绒毛 |

### 通用底毛（所有状态共享）

| 项目 | 约束 | 提示词 |
|---|---|---|
| 质感 | 真实毛发清晰自然、有层次 | 真实毛发、realistic detailed fur |
| 光泽 | 柔和自然光泽 | 柔和光泽、soft sheen |
| 种属特征 | 保持底模耳形/口鼻/胡须 | 保留种属特征、consistent animal features |
| 禁止 | 卡通化/插画/塑料感/玩具感 | — |

## 五、服饰约束（L3+L4）

> **宠物服饰原则**：以下均为**宠物专用服饰**（为动物身形设计、贴合兽体、为四肢尾巴预留位），**非人类成衣**；以上身/披挂为主，下半身保留覆毛兽腿与爪足。

### 服饰矩阵（宠物服饰）

| 风格 | 款式 | 适用 | 提示词 |
|---|---|---|---|
| 居家休闲 | 宠物卫衣/宠物小背心/宠物针织 | 居家、日常 | 宠物卫衣、柔软宠物针织、pet hoodie |
| 出街休闲 | 宠物外套/宠物披风/宠物围嘴 | 出游、逛街 | 宠物外套、温馨宠物穿搭、pet cape |
| 文艺 | 宠物小披肩/宠物围嘴/宠物毛衣 | 文艺、约会 | 宠物披肩、柔和色调、pet shawl |
| 职业感 | 宠物小马甲 + 项圈领结 | 上班、正式 | 宠物马甲、项圈领结、pet vest with bow tie |
| 运动 | 宠物运动背心/魔术贴外套 | 运动、活泼 | 宠物运动背心、活力穿搭 |
| 节日盛装 | 宠物节日服饰/宠物斗篷 | 节日 | 宠物节日盛装、温馨华丽 |

### 服饰通用约束

| 项目 | 约束 | 提示词 |
|---|---|---|
| 主色 | 中低饱和暖色为默认 | 柔和色调、温馨配色 |
| 部位 | **以上半身着装为主**，下半身默认保留动物覆毛后腿与爪足、不穿长裤（避免人腿剪影） | 上装为主、bare furry hind legs、no trousers |
| 材质 | 自然布料质感、半立体体积 | 自然布料、soft fabric volume |
| 适配 | 须为动物身躯量身适配，预留尾巴位 | 适配动物身躯、尾巴预留位 |
| 层次 | 自然层叠、柔和褶皱 | 自然层次、柔和褶皱 |

> **🔍 未覆盖场景推断规则**
>
> 当用户描述的场景/情境不在上表时，根据本风格核心基因自行推断：
>
> | 推断维度 | 宠物拟人Vlog基因 |
> |---|---|
> | 面部状态 | 默认自然萌态；活力/欢乐→活力精神态；休憩/睡前→慵懒放松态；受挫/生病→委屈柔弱态 |
> | 头部造型 | 日常→自然打理；出游→帽饰；俏皮/节日→发夹头巾或节日头饰 |
> | 服饰 | 所有服饰须为动物身躯适配并预留尾巴位；柔和色调；温馨自然布料 |
> | 配饰繁度 | 默认简约；出游→背包围巾；节日→节日配饰 |
> | 色调倾向 | 中低饱和暖色系（奶油白/焦糖棕/暖阳橙/蜜桃粉）；治愈柔和 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 纯净中性灰 #E8E8E8 |
| 站姿 | 动物自然后腿立起、含背微弓、趾行爪足、前爪收胸前或轻搭身侧（**禁止任何姿态变化**） |

| 光线 | 自然写实光，真实毛发细节清晰 |
| 一致性 | 四视图的种属/毛色/造型/服饰/配饰/尾巴完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

| 禁止输出 | 速查表、分层构建方案、视觉约束表、禁止事项表、衍生方案、输出建议、核心要素表等一切非提示词内容 |

## 十、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 叠加后种属头部特征与轮廓必须与底模一致 |
| R2 | 服饰必须为动物身躯适配并预留尾巴位 |
| R3 | 头饰必须为动物耳朵预留位置、自然贴合 |
| R4 | 面部状态/造型/服饰/配饰风格统一 |
| R5 | 必须输出四视图设定图（头部特写+正视图+侧视图+后视图） |
| R6 | 必须指定「纯净中性灰背景」 |
| R7 | 必须指定「四视图一致性」并保留尾巴 |
| R8 | **仅输出提示词**——禁止输出速查表/分层方案/视觉约束/禁止事项/衍生方案/输出建议等任何非提示词内容 |
| R9 | **禁止包含场景描述**——人物衍生资产不涉及场景/环境/天气/背景叙事 |
| R10 | **禁止道具交互**——不包含任何手持物/交互物，道具属于独立资产类型 |
| R11 | **姿态保持不变**——必须保持底模动物自然后腿立起姿态，禁止任何动作/体态/姿势变化 |
| R12 | **L1 必须先分析再决策**——先解析用户面部线索，再确定自然态/精神态/特殊态 |
| R13 | **道具/场景/动作不作强度升级依据**——仅凭道具、环境、动作等信息不得改变面部状态决策 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 叠加后种属特征改变或轮廓偏移 |
| X2 | 失去真实动物身体特征变成纯人类/人形化躯干 |
| X3 | 面部状态/服饰风格互相冲突 |
| X4 | 复杂场景背景（必须纯灰底） |
| X5 | 四视图间服化造型不一致 |
| X6 | 输出提示词以外的任何内容（表格/方案/建议/解释/变体等） |
| X7 | 在人物衍生资产中加入场景描述（街道/咖啡馆/室内/天气等环境元素） |
| X8 | 输出「核心要素速查」「分层构建方案」「视觉约束」「禁止事项」「衍生方案」等章节 |
| X9 | 加入任何道具交互（手持马克杯/相机/书/玩具等物品） |
| X10 | 改变底模姿态（行走/回眸/举手/侧身/奔跑/趴卧等动作描述） |
| X11 | 加入表情与姿态联动的叙事性描写 |
| X12 | 未分析用户线索就直接套用固定状态 |
| X13 | 四视图设定图中出现四足趴卧爬行姿态（设定图为操作态后腿坐起/立起；四足兽态仅用于分镜走路/移动镜头） |
| X14 | 卡通/插画/黏土/塑料感/玩具感等非写实质感 |
| X15 | 恐怖/怪诞/扭曲拟人造型 |
