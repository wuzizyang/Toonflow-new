# 宠物拟人化Vlog（Pet Anthropomorphic Vlog）风格说明

本风格专为"宠物拟人化Vlog（Pet Anthropomorphic Vlog）"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **宠物拟人化**：以猫、狗、兔等常见宠物为原型，完整保留**真实动物的全身特征**（头部、口鼻、胡须、尾巴、四肢、全身逐根真实毛发与真实动物体态比例），**仅在行为上拟人**——以"动物自然后腿立起"的姿态（含背微弓、前爪收于胸前、趾行爪足，**而非人类笔直站立**）做人类生活的事，上半身穿戴人类服饰、下半身保留覆毛兽腿与爪足。即使立起，身体也必须读作"一只真动物用后腿站了起来"，保留真实兽态（相对大头、短身圆润、短小覆毛四肢、真实前爪），**避免人类化的修长躯干、宽肩、五指人手、挺直军姿与人腿剪影**，呈现"真实宠物过着人类生活"的可爱反差感。
- **照片级写实质感**：以**真实照片实拍**为标准（照片级写实摄影，像真实相机拍下而非CG/3D渲染），逐根真实毛发、皮毛层次、次表面散射光泽、真实解剖结构与电影级光照，追求以假乱真的真实感。
- **Vlog生活美学**：在拟人化基础上追求真实生活感，画面像日常Vlog记录——居家、咖啡馆、街头、出游，氛围轻松随性、温暖治愈、生活气息浓厚。
- **情感表达**：适合展现温馨、治愈、幽默、日常陪伴的内容，强调真实拟人反差与生活仪式感下的情感共鸣。

## 适用范围

- 宠物拟人化Vlog题材的AI美术生成（角色、场景、道具、分镜等）
- 需要照片级写实毛发质感、真实摄影实拍质感、生活Vlog氛围的视觉创作

## 严禁内容

- 卡通/插画/黏土/2.5D扁平/玩具感等非写实质感
- 恐怖/怪诞拟人、人兽不分的扭曲造型
- 失去真实动物身体特征（头部/体态/毛发）的纯人类或人形化角色
- 黑暗暴力、成人向内容

## 风格体验

在本风格下，您将体验到：

- 角色保留真实动物的全身毛发与体态特征（头部+身体+四肢+尾巴），以"动物自然后腿立起"的姿态从事人类生活、上身穿戴人类服饰，气质亲切真实
- 场景为生活化空间（居家/咖啡馆/街头/户外），氛围温暖随性、充满Vlog记录感
- 道具、日常物品均为真实质感的生活物件，质感温润可信
- 分镜与画面以Vlog镜头语言为基础，强调日常叙事与陪伴式情感表达

---

本风格仅适用于"宠物拟人化Vlog（Pet Anthropomorphic Vlog）"相关项目。如需其他风格（如写实3D、2D扁平、古风插画等），请勿使用本套提示词。
