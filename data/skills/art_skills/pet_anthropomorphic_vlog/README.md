# 宠物拟人化Vlog（Pet Anthropomorphic Vlog）风格说明

本风格专为"宠物拟人化Vlog（Pet Anthropomorphic Vlog）"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **宠物拟人化**：以猫、狗、兔等常见宠物为原型，赋予其直立人形身躯与人类生活行为，同时完整保留动物头部特征（耳朵、口鼻、绒毛、尾巴），呈现"毛绒朋友过着人类生活"的可爱反差感。
- **治愈毛绒质感**：以柔软绒毛、圆润造型、半立体（2.5D）插画质感为标准，强调毛发蓬松柔软、皮克斯式的可爱体积感与温暖光泽。
- **Vlog生活美学**：在拟人化基础上追求真实生活感，画面像日常Vlog记录——居家、咖啡馆、街头、出游，氛围轻松随性、温暖治愈、生活气息浓厚。
- **情感表达**：适合展现温馨、治愈、幽默、日常陪伴的内容，强调萌系反差与生活仪式感下的情感共鸣。

## 适用范围

- 宠物拟人化Vlog题材的AI美术生成（角色、场景、道具、分镜等）
- 需要毛绒可爱质感、半立体插画风、生活Vlog氛围的视觉创作

## 严禁内容

- 写实动物纪录片质感、照片级真实动物
- 恐怖/怪诞拟人、人兽不分的扭曲造型
- 失去动物头部特征的纯人类角色
- 黑暗暴力、成人向内容

## 风格体验

在本风格下，您将体验到：

- 角色保留动物头部与绒毛特征、却拥有人形身躯与人类穿搭，气质萌趣亲切
- 场景为生活化空间（居家/咖啡馆/街头/户外），氛围温暖随性、充满Vlog记录感
- 道具、日常物品均为可爱拟人尺度的生活物件，造型圆润、质感温润
- 分镜与画面以Vlog镜头语言为基础，强调日常叙事与陪伴式情感表达

---

本风格仅适用于"宠物拟人化Vlog（Pet Anthropomorphic Vlog）"相关项目。如需其他风格（如写实3D、2D扁平、古风插画等），请勿使用本套提示词。
