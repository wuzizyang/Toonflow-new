## 一、单镜头表演节奏表模板

> 本类型不使用传统多镜头分镜表。以下是单镜头短视频的**表演节奏表**模板。

### 基本信息

```
- 角色：{角色名}（{品种}）
- BGM：{曲名/风格} · BPM {数值}
- 时长：{秒数}（≤18s）
- 镜头结构：单镜头（single shot）
- 宠物服饰：{服饰描述}
- 场景/背景：{场景描述}
- 色调方向：{情绪色盘}
```

### 表演节奏表

| 时间 | 音乐阶段 | 角色动作 | 景别 | 运镜微调 | 表情/情绪 |
|------|---------|---------|------|---------|----------|
| 0.0-3.0s | 前奏/起拍 | 角色静坐，耳朵微动 | 中景 | 固定 | 好奇、等待 |
| 3.0-6.0s | 主歌起 | 萌态律动开始，脑袋左右晃 | 中景 | 缓推近景 | 开心、律动 |
| 6.0-10.0s | 副歌/重拍 | 动作幅度加大，前爪摆动/摇摆 | 近景 | 固定 | 活力、享受 |
| 10.0-14.0s | 高潮段 | 最萌动作（歪头/趴地拍爪/小跳） | 近景 | 缓推特写 | 惊喜、可爱 |
| 14.0-18.0s | 尾奏 | 动作渐缓，定格pose | 拉回中景 | 缓拉 | 满足、回味 |

## 二、视频生成提示词对照表

| 分镜阶段 | 提示词要点 |
|----------|-----------|
| 建立期 | 角色静坐 + 耳朵微动 + 中景 + 固定镜头 + 好奇表情 |
| 发展期 | 萌态律动 + 摆头/摇摆 + 缓推 + 开心表情 |
| 高潮期 | 最萌动作 + 定格pose + 特写 + 可爱表情 |
| 收束期 | 动作渐缓 + 回归静坐 + 缓拉 + 满足表情 |

## 三、多视频换装系列表模板

> 同一角色同一BGM，每条视频换一套服饰，发布为系列。

### 系列信息

```
- 角色：{角色名}（{品种}）
- BGM：{曲名/风格}（系列共用）
- 系列数量：{N}条
- 发布平台：{平台列表}
```

### 系列分镜

## 四、导演自检清单

### 表演节奏自检
- [ ] 前3秒是否建立了角色形象？
- [ ] 中间段动作是否从小到大递进？
- [ ] 高潮段是否有最萌动作/定格pose？
- [ ] 收束段是否有渐缓/凝固？
- [ ] 整体节奏是否与BGM匹配？

### 视觉质量自检
- [ ] 角色兽态是否全程保持（无人形化）？
- [ ] 3D渲染质感是否一致？
- [ ] 毛发细节是否清晰？
- [ ] 服饰是否贴合动物身形？
- [ ] 背景色与角色色是否有足够对比？

### 时长合规自检
- [ ] 总时长≤18秒？
- [ ] 每个阶段时间分配合理？
