## 一、单镜头视频描述模板

> 本类型为**单镜头一镜到底**，不拆分镜、不按秒分段。以下是整条视频的整体描述模板。

### 基本信息

```
- 角色：{角色名}（{品种}）
- BGM：{曲名/风格} · BPM {数值}
- 时长：{秒数}（≤18s）
- 镜头结构：单镜头（single shot），一镜到底
- 宠物服饰：{服饰描述}
- 场景/背景：{场景描述}
- 色调方向：{情绪色盘}
- 运镜：{固定/缓推/缓拉}，{景别}
```

### 整体表演描述（单段连续）

> 用一段连续的自然语言描述整条视频的萌态律动流转，**不要按秒拆分时间段**，不要做成分镜表。

```
{角色名}在{场景}中{起始姿态}，随着BGM节拍自然展开萌态律动：
{连续动作流转描述——从静到动、从轻到重、高潮定格、渐缓收束的自然过渡}。
全程{景别}，{运镜方式}，{情绪基调}。
```

**示例**：
```
呼呼在浅粉到奶油白渐变背景前安静坐着，耳朵微动，琥珀色眼睛好奇看向镜头。
随着吉他BGM起，脑袋开始随节拍左右轻晃，耳朵跟着弹动，尾巴尖有了自己的节奏。
律动递进，后腿坐起，前爪随节拍左右摆动，身体左右摇摆，尾巴大幅摆动，银白毛发蓬松飘动。
高潮瞬间歪头，单前爪举起定格，圆眼睁大，耳朵竖直，胡须前探，奶凶奶凶的。
最后动作渐缓，前爪放下，脑袋回正，眼睛眯起，自然放松定格。
全程中景为主，镜头固定，自然好奇基调。
```

## 二、视频生成提示词（单段连续）

> 与表演描述对应，生成提示词也是**单段连续描述**，不拆分镜。

### 提示词结构

```
[风格锚定] + [角色描述] + [服饰] + [连续动作流转] + [场景/背景] + [光影] + [运镜] + [情绪/表情]
```

### 关键原则

- **动作描述连续自然**：用 "starts... then... as... finally..." 等连接词描述流转，不用 "0-3s... 3-6s..." 时间分段
- **运镜单一稳定**：整条视频只用一种运镜方式（推荐固定），不频繁切换
- **景别尽量一致**：如需变化只做缓慢推拉，不跳跃切换
- **情绪连贯**：用 "throughout" / "全程" 描述整体情绪，不按段切换表情

## 三、多视频换装系列模板

> 同一角色同一BGM，每条视频换一套服饰，发布为系列。每条视频仍是单镜头一镜到底。

### 系列信息

```
- 角色：{角色名}（{品种}）
- BGM：{曲名/风格}（系列共用）
- 系列数量：{N}条
- 发布平台：{平台列表}
```

### 系列视频清单

| 序号 | 宠物服饰 | 场景/背景 | 色调方向 | 差异化要点 |
|------|---------|----------|---------|-----------|
| 1 | {服饰A} | {场景A} | {色盘A} | {差异化描述} |
| 2 | {服饰B} | {场景B} | {色盘B} | {差异化描述} |
| 3 | {服饰C} | {场景C} | {色盘C} | {差异化描述} |
| ... | ... | ... | ... | ... |

> 每条视频内部仍是单段连续描述，不拆分镜。

## 四、导演自检清单

### 单镜头连贯性自检
- [ ] 整条视频是否为单镜头一镜到底，无剪切转场？
- [ ] 动作描述是否为连续流转，未按秒拆分时间段？
- [ ] 运镜是否单一稳定（推荐固定），未频繁切换？
- [ ] 景别是否一致或仅缓慢推拉，未跳跃切换？

### 表演节奏自检
- [ ] 整体律动是否有起伏感（静→动→高潮→收束）？
- [ ] 高潮段是否有最萌动作/定格pose？
- [ ] 收束段是否有渐缓/凝固？
- [ ] 整体节奏是否与BGM匹配？

### 视觉质量自检
- [ ] 角色真实兽态是否全程保持（无人形化、无卡通化）？
- [ ] 写实3D渲染质感是否一致？
- [ ] 毛发细节是否真实有密度变化？
- [ ] 服饰是否贴合动物身形？
- [ ] 背景色与角色色是否有足够对比？

### 时长合规自检
- [ ] 总时长≤18秒？
