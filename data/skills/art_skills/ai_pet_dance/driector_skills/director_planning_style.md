## 一、视觉风格定义

### 核心风格锚定

| 维度 | 定义 |
|------|------|
| 渲染风格 | 写实3D渲染（cinematic 3D render），接近电影级VFX写实动物质感（如《狮子王2019》《森林王子》），真实动物解剖与毛发，非Pixar卡通 |
| 角色形态 | 全身真实兽态，写实3D渲染，自然头身比1:3-4（接近真实幼宠比例，不夸张大头化） |
| 毛发 | 写实3D渲染毛发，自然密度变化与层次，真实光泽，逐根可见，无卡通化平涂 |
| 光影 | 自然光影，柔和环境光+真实阴影+次表面散射，电影感打光 |
| 色彩 | 自然饱和度，暖色为主基调，服饰色彩真实丰富但不卡通化 |

### 与 pet_anthropomorphic_vlog 的风格隔离

> **本风格严禁混入以下 pet_anthropomorphic_vlog 的风格元素**：
> - `handheld phone footage` / `shot on iPhone` / 手机vlog自拍视角——本风格是电影级3D舞台视角
> - 人类化自拍运镜——本风格是稳定电影机位

### 与卡通风格的隔离（重点）

> **本风格严禁混入卡通化元素**：
> - `Pixar quality` / `Disney style` / `CG cartoon` / `cute proportions`——本风格不是卡通
> - `chibi` / `super deformed` / `big cartoon eyes` / `exaggerated proportions`——本风格是真实动物比例
> - 卡通化平涂毛发 / 塑料感绒毛——本风格是写实3D毛发
> - 扁平化面部 / 夸张大眼眶——本风格是真实动物五官

## 二、光影方案

| 方案 | 适用场景 | 描述 | 提示词方向 |
|------|---------|------|-----------|
| **柔光棚拍** | 默认方案 | 均匀柔和的3D渲染光，角色清晰，背景干净 | soft studio lighting, even illumination, subtle shadows |
| **舞台聚光** | 表演型内容 | 聚光灯效果，角色明亮，背景暗 | dramatic spotlight, dark background, stage lighting |
| **霓虹炫彩** | 潮牌/夜店风 | 多彩霓虹光晕，时尚感 | neon glow, colorful rim lighting |
| **自然光** | 户外/日常场景 | 模拟自然阳光，温暖柔和 | warm natural sunlight, soft shadows |
| **纯色渐变背景** | 换装展示 | 纯色或渐变色背景，突出角色和服饰 | clean gradient background, soft lighting |

## 三、色彩使用规则

### 色彩层级

| 层级 | 约束强度 | 说明 |
|------|---------|------|
| L1 硬约束 | 高 | 角色毛色、瞳色——跨视频跨服饰永远锁定 |
| L2 软约束 | 中 | 服饰色、场景色——按内容类型和情绪调整 |
| L3 例外 | 低 | 节日/特殊场景可临时突破，但保留萌趣治愈基调 |

### 色彩搭配原则

- **角色毛色+服饰色+背景色**三者形成层次感，不融合不冲突
- 暖色为主基调（C1/C2/C3/C6/C8），冷色用于背景或点缀（C5/C10）
- 节日内容可用更饱和的色彩，但避免荧光色

## 四、质感约束

| 维度 | 要求 | 严禁 |
|------|------|------|
| 毛发 | 写实3D渲染，自然密度变化与层次，逐根可见，真实光泽，有真实分缝 | 塑料感、橡胶感、无细节纯色、卡通化平涂、Q版绒毛 |
| 服饰 | 写实3D渲染织物质感，有真实纹理和褶皱 | 平面贴图、无质感、卡通化色块 |
| 背景 | 写实3D渲染环境，有空间感和真实光影层次 | 2D平面背景、卡通化背景、玩具感场景 |
| 整体 | 电影级写实3D渲染质感（cinematic 3D render） | Pixar/Disney卡通、2D插画、黏土、玩具感、Q版手办感 |
| 解剖 | 真实动物骨骼、肌肉、皮肤纹理 | 卡通化球身、夸张比例、扁平化面部 |

## 五、画面质量标准

| 项目 | 标准 |
|------|------|
| 分辨率 | 1080P起步（1920x1080或1080x1920） |
| 毛发细节 | 逐根可见，自然密度变化，蓬松有层次，无卡通平涂 |
| 解剖细节 | 真实动物骨骼、肌肉、皮肤纹理，无卡通化变形 |
| 光影一致性 | 全片光影方向统一，无矛盾光源，自然光感 |
| 色彩一致性 | 角色毛色跨镜头一致，无漂移 |
| 运动稳定性 | 单镜头内角色形态不"融化"不变形 |
