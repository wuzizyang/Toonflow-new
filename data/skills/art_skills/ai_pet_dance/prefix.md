## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：毛色、眼睛、动物种属特征的审美方向 |
| L2 软约束 | 中 | 场景色、服饰色、点缀色优先参考色盘，可按镜头与剧情微调 |

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「3D渲染质感 + 纯兽态 + 可爱化比例」风格锚定词：`3D render, Pixar quality, CG animation, cute proportions` |
| R2 | 必须声明「保留真实动物全身特征与体态」+ **萌态舞蹈姿态**：后腿坐起/立起 + 前爪随节拍摆动；身体不可人形化、不可人类直立行走 |
| R3 | 毛发必须使用「3D渲染毛发，蓬松有光泽，逐根可见」（3D rendered fur, fluffy and glossy, individually visible strands）；着装为**宠物专用服饰** |
| R4 | 造型必须使用「可爱化真实解剖结构 + 1:2.5-3头身比」，萌来自比例和神态，不是人类化 |
| R4b | **小兽尺度**：角色是3D可爱化的小动物（头身比1:2.5-3），同框出现参照物时，角色与参照物的大小关系必须符合小兽尺度 |
| R5 | 氛围必须声明「3D渲染舞台感 + 柔和环境光 + 清晰阴影 + 萌趣可爱」 |
| R6 | 角色须**优先展现呆萌可爱**：圆润大眼、无辜眼神、微微歪头、放空发呆、笨拙可爱的小动作与种属本能破功的萌点 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「照片级写实/photorealistic」——本风格是3D渲染质感，不是真实相机拍下 |
| X2 | 严禁「失去真实动物身体特征（头部/体态/毛发）的纯人类或人形化躯干角色」 |
| X3 | 严禁「高饱和荧光色/赛博霓虹色」 |
| X4 | 严禁「恐怖/怪诞/扭曲拟人/人兽不分的畸形造型」 |
| X5 | 严禁「黑暗暴力/惊悚/成人向内容」 |
| X6 | 严禁「直立行走/人类化迈步走路」——萌态律动用后腿坐起/立起+前爪摆动，非人类化舞蹈 |
| X6b | 严禁「过度拟人」：人类化修长躯干/宽肩锁骨/修长手臂/灵巧人手/挺直军姿/垂直脊柱；身体须保留真实兽态（大头短身、圆润肚腩、短小四肢、真实前爪） |
| X6c | 严禁「人腿剪影」与人类长裤/长袜遮盖后腿造成人类双腿轮廓。着装为宠物专用服饰、以上身/披挂为主，下半身保留动物覆毛短腿 |
| X7 | 严禁「塑料感/橡胶感/无细节的纯色绒毛」，3D毛发必须真实有层次与光泽 |
| X8 | 严禁「角色尺度违反真实世界逻辑」：不得把小动物放大到人类尺寸 |
| X9 | 严禁「多镜头剪辑/转场」——本类型为单镜头（single shot），不剪切不拼接 |

| 风险词（禁止出现在输出中） | 安全替换表述 |
|---|---|
| dwarf / dwarfism / dwarfed / 侏儒 / 侏儒症 / midget | short-legged / 短腿 / 矮脚（如 `short-legged Munchkin cat`；**禁止出现 dwarf 任何词形**） |
| 暴露 / 性化 / 性感 / 内衣 / 裸 / nude / naked / bare / lingerie | 着装得体、完整覆盖躯干（decent outfit, fully covered torso） |
