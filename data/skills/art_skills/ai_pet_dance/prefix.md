> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：毛色、眼睛、动物种属特征的审美方向 |
| L2 软约束 | 中 | 场景色、服饰色、点缀色优先参考色盘，可按镜头与剧情微调 |

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「写实3D渲染 + 纯兽态 + 真实动物解剖」风格锚定词：`cinematic 3D render, photorealistic animal fur, realistic anatomy, natural lighting` |
| R2 | 必须声明「保留真实动物全身解剖特征与体态」+ **萌态舞蹈姿态**：后腿坐起/立起 + 前爪随节拍摆动；身体不可人形化、不可人类直立行走 |
| R3 | 毛发必须使用「写实3D渲染毛发，自然密度与层次，真实光泽，逐根可见」（photorealistic 3D fur, natural density and layering, realistic sheen, individually visible strands）；着装为**宠物专用服饰** |
| R4 | 造型必须使用「真实动物解剖结构 + 自然头身比1:3-4」，萌态来自真实动物本身的可爱特征与神态，不是夸张卡通化比例 |
| R4b | **小兽尺度**：角色是真实小动物尺度（头身比1:3-4），同框出现参照物时，角色与参照物的大小关系必须符合真实小兽尺度 |
| R5 | 氛围必须声明「写实3D渲染电影感 + 自然光影 + 真实环境光 + 柔和景深」 |
| R6 | 角色须**通过真实动物特征展现可爱**：真实圆润眼形、自然好奇眼神、微微歪头、动物本能的小动作与种属特征的萌点；不得通过夸张卡通化放大眼眶或变形五官实现可爱 |
| R7 | **真实解剖细节**：必须保留真实动物骨骼结构、自然肌肉线条、真实毛发密度变化（背部密/腹部软/面部短）、真实瞳孔虹膜反光、真实鼻头湿润质感、真实肉垫纹理 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「Pixar/Disney卡通化 / exaggerated cartoon proportions / chibi / 大头娃娃式夸张比例」——本风格是写实3D渲染，不是卡通 |
| X2 | 严禁「失去真实动物身体特征（头部/体态/毛发）的纯人类或人形化躯干角色」 |
| X3 | 严禁「高饱和荧光色/赛博霓虹色」 |
| X4 | 严禁「恐怖/怪诞/扭曲拟人/人兽不分的畸形造型」 |
| X5 | 严禁「黑暗暴力/惊悚/成人向内容」 |
| X6 | 严禁「直立行走/人类化迈步走路」——萌态律动用后腿坐起/立起+前爪摆动，非人类化舞蹈 |
| X6b | 严禁「过度拟人」：人类化修长躯干/宽肩锁骨/修长手臂/灵巧人手/挺直军姿/垂直脊柱；身体须保留真实兽态（真实动物头骨、自然短身、短小四肢、真实前爪） |
| X6c | 严禁「人腿剪影」与人类长裤/长袜遮盖后腿造成人类双腿轮廓。着装为宠物专用服饰、以上身/披挂为主，下半身保留动物覆毛短腿 |
| X7 | 严禁「塑料感/橡胶感/无细节的纯色绒毛/卡通化平涂毛发」，3D毛发必须真实有层次、有密度变化、有自然光泽 |
| X8 | 严禁「角色尺度违反真实世界逻辑」：不得把小动物放大到人类尺寸 |
| X9 | 严禁「多镜头剪辑/转场/拆分镜」——本类型为单镜头（single shot）一镜到底，不剪切不拼接，不按秒拆分时间段，动作描述必须连续流转 |
| X10 | 严禁「卡通化五官」：夸张大眼眶/夸张圆瞳/卡通化微笑弧线/扁平化面部；五官必须遵循真实动物解剖 |
| X11 | 严禁「2D插画/赛璐璐/黏土/玩具感/Q版手办感」——必须是写实3D渲染质感 |
| X12 | **场景图（scene）与工具图（prop）严禁包含任何角色/动物/宠物/人类/模特**——场景图只画纯环境，工具图只画纯道具；角色资产只在 `art_character.md` 与 `art_character_derivative.md` 中定义，避免"场景里画出一只不同的猫"导致参考图污染 |

## 四、敏感词规避（过审约束）

> 输出提示词时**必须主动规避图像/视频平台文本审核的敏感词**，用下表的安全表述替换。

| 风险词（禁止出现在输出中） | 安全替换表述 |
|---|---|
| dwarf / dwarfism / dwarfed / 侏儒 / 侏儒症 / midget | short-legged / 短腿 / 矮脚（如 `short-legged Munchkin cat`；**禁止出现 dwarf 任何词形**） |
| 暴露 / 性化 / 性感 / 内衣 / 裸 / nude / naked / bare / lingerie | 着装得体、完整覆盖躯干（decent outfit, fully covered torso） |
| 描述下半身时的"无衣/裸露"式表述 | 只用"覆毛兽腿、自然动物后腿与爪足"（fluffy animal hind legs） |
| 幼 / 年幼 / 孩童 / loli / child | 用体型尺度词替代：small animal scale / 小兽尺度 |
| 血腥 / 暴力 / 恐怖 / 畸形 / deformed | 删除或改为中性表述 |
| 过度解剖细节：paw feet / toe beans / paw pads | 省略，或仅用 `short legs` / `paws` / 短腿 / 前爪 简述 |
| "非人类/not human"否定式 | 正面陈述：`pet clothing`、`cat paws`、`short legs` |
| 偷拍 / 偷窥 / sneak photography / candid | 改用中性视角词：observational POV / low camera angle |
